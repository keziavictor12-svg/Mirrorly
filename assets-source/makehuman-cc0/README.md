# Mirrorly MakeHuman CC0 sources

These files are retained so Mirrorly's CC0 true-3D assets can be rebuilt and audited.

## Shipped assets

- `toigo_curled_under_bob/` builds `public/assets/models/bob-cc0.glb`.
- `long01/` builds the geometry-shaped `v-cut-cc0.glb` and `u-cut-cc0.glb`.
- `short01/` builds `short-cc0.glb` for Crew Cut.
- `short02/` builds the close-shaped `buzz-cut-cc0.glb`.
- `short03/` builds the center-part-shaped `curtain-bangs-cc0.glb`.
- `short04/` builds the side-tapered `skin-fade-cc0.glb`.

`cortu_short_messy_hair/` was evaluated as an alternative short style but is not referenced by the application. Feather Cut's separately licensed source is documented under `../makehuman-cc-by/`.

## Rebuild

From `MirrorlyLaptopApp` run:

```powershell
npm install
npm run build:3d-assets
```

The build preserves the original source meshes, regenerates the five shaped variants, removes stale normals so Three.js recalculates them at load time, embeds textures, and writes all eight browser-ready GLBs.
